# Contributing

This is a starter repo for hackathon participants, so most of you will work in your own fork.

## For your own project

1. Fork this repository (or use it as a template).
2. Create a new branch for your work.
3. Commit early and often.
4. Push to your fork and keep your commit history clean for judges.

## Improving this starter

Found a bug or want to add a helpful example? Open a pull request with a clear description of the change.
