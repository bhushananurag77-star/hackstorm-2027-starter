# HackStorm 2027 Starter

Starter repository for **HackStorm 2027**, a 36-hour hackathon for 200 participants.

Use this repo as your starting point. Fork it or click **Use this template** to create your own copy.

## Quickstart

```bash
git clone https://github.com/<your-username>/hackstorm-2027-starter.git
cd hackstorm-2027-starter
```

Pick a track and start building. See `examples/` for a minimal starter.

## Tracks

- AI & Machine Learning
- Web & Mobile
- Hardware & IoT
- Social Impact & Health
- FinTech & Web3

## Deadline

Hacking ends **Sunday 24 January 2027, 06:00 IST**. Submit on the official platform before the deadline.

## Need help?

Find a mentor at the mentor desk or ask in the Discord.
